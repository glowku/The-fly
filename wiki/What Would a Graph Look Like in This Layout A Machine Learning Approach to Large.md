# What Would a Graph Look Like in This Layout? A Machine Learning Approach to Large Graph Visualization

Ce papier présente une approche de visualisation de grands graphes basée sur l’apprentissage automatique. En se concentrant sur la similarité topologique, les auteurs proposent de prédire l’apparence d’un graphe sous différents agencements sans devoir les calculer explicitement. Cette méthode vise à réduire drastiquement le coût computationnel tout en conservant la pertinence esthétique des représentations.
