# SecuCode: Intrinsic PUF Entangled Secure Wireless Code Dissemination for Computational RFID Devices

SecuCode est un mécanisme de mise à jour logicielle sans fil sécurisé conçu spécifiquement pour les dispositifs RFID à puissance auto‑alimentée (CRFID). En s’appuyant sur la fonction physique non clonable (PUF) intégrée dans la mémoire SRAM, SecuCode permet d’authentifier et de chiffrer les mises à jour de firmware tout en respectant les contraintes de puissance intermittente et de ressources limitées propres aux CRFID.
