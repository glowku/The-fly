# GitHub

GitHub est une plateforme de collaboration dédiée aux développeurs, permettant la création, le stockage, la gestion et le partage de code source. Elle repose sur Git, le système de contrôle de version distribué, et propose des fonctionnalités supplémentaires telles que le contrôle d’accès, le suivi des bugs, les demandes de fonctionnalités, la gestion des tâches, l’intégration continue et les wikis. Basée à San Francisco, GitHub est une filiale de Microsoft depuis 2018.

## Fonctionnalités

GitHub offre un environnement complet pour le développement logiciel. Le contrôle d’accès granulaire permet de gérer les permissions au niveau des dépôts, des branches ou des fichiers. Le système de suivi des problèmes (issues) et des demandes de tirage (pull requests) facilite la collaboration et la révision de code. Les workflows d’intégration continue (CI) sont intégrés via GitHub Actions, permettant d’automatiser les tests, les builds et les déploiements. Les wikis associés à chaque projet servent de documentation vivante, tandis que les projets (project boards) permettent de planifier et de suivre les tâches.

## Historique et acquisition

GitHub a été fondé en 2008 par Tom Preston‑Lively, Chris Wanstrath et PJ Hyett. La plateforme a rapidement gagné en popularité grâce à son interface conviviale et à son adoption massive par la communauté open‑source. En 2018, Microsoft a acquis GitHub pour 7,5 milliards de dollars, tout en conservant son modèle d’exploitation indépendant. Depuis l’acquisition, GitHub a étendu ses services, notamment en introduisant GitHub Enterprise, GitHub Actions et GitHub Copilot, tout en renforçant la sécurité et la conformité pour les entreprises.

## Impact et utilisation

GitHub est devenu le référentiel de choix pour des millions de projets open‑source et privés. Il sert de plateforme de découverte, de partage et de collaboration, favorisant l’innovation dans le développement logiciel. Les entreprises l’utilisent pour héberger leurs projets internes, gérer leurs pipelines CI/CD et maintenir la traçabilité des modifications. La communauté GitHub contribue également à l’éducation en offrant des ressources, des tutoriels et des projets d’apprentissage accessibles à tous.
