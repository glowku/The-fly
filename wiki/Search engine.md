# Search engine

Un moteur de recherche est une application de recherche qui fournit des liens vers des pages web et d’autres informations pertinentes sur le Web en réponse à une requête utilisateur. Les utilisateurs soumettent leurs requêtes via un navigateur web ou une application mobile, et la page de résultats affiche généralement une collection d’hyperliens accompagnés de brèves descriptions et d’images pertinentes. Les moteurs de recherche offrent également la possibilité de restreindre une recherche à des types de résultats spécifiques, tels que les images, les vidéos ou les actualités.
