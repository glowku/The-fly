# JSON streaming

## Source
Wikipedia — https://en.wikipedia.org/wiki/JSON_streaming

## Extrait
JSON streaming refers to communications protocols to delimit JSON objects. These are typically built upon lower-level stream-oriented protocols (such as TCP). A streaming JSON protocol is often required to ensure that individual JSON objects are recognized by a client. A server and client often have to agree on the same JSON streaming protocol in order to product and consume events effectively.
