# Git

## Source
Wikipedia — https://en.wikipedia.org/wiki/Git

## Extrait
Git is a distributed version control software system that is capable of managing versions of source code or data. It is often used to control source code by programmers who are developing software collaboratively. It was originally created by Linus Torvalds for version control in the development of the Linux kernel.
